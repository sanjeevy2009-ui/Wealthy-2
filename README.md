# 💰 WEALTHY

**Track. Understand. Save.**

A premium India-focused personal finance SaaS — full-stack with 3D metallic card, glassmorphism auth, and 13 fully working pages.

## ✨ Features

- 🔐 Full Auth System — Sign up / Sign in with JWT
- 🃏 3D Rotating Card — Play/pause SVG toggle + 8 metallic colors
- 📊 13 Pages — Overview, Transactions, Analysis, Calendar, Accounts, UPI, Cash Flow, Bills, Budgets, Savings, Reports, Settings, Help
- 🎨 Glassmorphism — Frosted glass auth screen
- 🌓 Light / Dark Mode
- 📱 Fully Responsive
- 🇮🇳 India-Focused — ₹ INR, UPI, HDFC/ICICI

## 🛠️ Tech Stack

- Frontend: HTML + CSS + JavaScript
- Backend: Node.js + Express
- Database: SQLite
- Auth: JWT + bcrypt

## 🚀 Run Locally

\`\`\`bash
npm install
npm start
\`\`\`

Open http://localhost:3000
